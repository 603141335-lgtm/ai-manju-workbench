# 快递快扫 v0.7

新增：
1. Excel 导出后可以选择“保存到手机文件夹 / 分享给微信、QQ等软件 / 选择软件打开 Excel”。
2. Excel 已保存后还可以立即分享或选择应用打开。临时分享文件在 cache/exports；文档由外部应用读取，不上传到软件开发者的服务器。
3. 照片缩略图支持点击全屏查看、双指放大平移、双击缩放。
4. 照片支持分享给其他应用和通过系统文件选择器另存到手机。
5. 快递扫码仍只识别一维条形码，不识别二维码；中文语音成功/重复/失败。
6. 原图仍保存在应用内部 files/photos；卸载会丢失。Excel 不包含图片本体。

v0.7 使用独立应用 ID com.kuaidi.quickscan.v07，与 v0.6 共存。两个版本的数据并不共享，切勿为了升级卸载含有未备份数据的旧版本。
