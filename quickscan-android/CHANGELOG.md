# 快递快扫 | 版本更新记录

## v0.8 | 2026-11-05
- 批次页：照片单选、多选、全选、取消选择；永久删除软件内部选中照片并解除关联。
- 确认删除前提示不可恢复；删除不影响快递单号、时间、备注和记录总数。
- 扫码画面移除中央“对准横向条形码”文字与上方重复提示。
- 构建通过 GitHub Actions 成功验证。
- Android 包名 `com.kuaidi.quickscan.v08`，与旧实验版隔离。

## v0.7 | 2026-11-05
- Excel 可直接分享到微信/QQ等、选择应用打开，或保存到手机文件夹。
- 图片支持全屏、缩放、分享、另存为。
- FileProvider 实现第三方应用临时读取权限。

## v0.6 | 2026-11-05
- 设计新版包裹图标与蓝色 UI。
- 中文语音：成功 / 重复 / 失败；震动与 TTS 开关。
- 原生 Office Open XML `.xlsx` 导出，完整明细 / 仅单号。
- 长数字按文本保存，避免科学计数法。

## v0.5 | 2026-11-05
- 首次通过 GitHub Actions 编译可安装的安卓 APK。
- 支持条形码扫码、拍照、批次、查询、CSV 导出、重复检查。

## 下次更新规范
每次更新都要补：版本号、变更内容、APK 编译检查、手机验证结论、已知限制。
