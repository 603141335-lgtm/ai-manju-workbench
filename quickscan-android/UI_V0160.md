# 快递快扫 v0.16.0 界面改版

基于原生 Android 工程 v0.15.0，原始提交 adb83b49cd18c7cf40c4cc6f9b58d9a00a3c8777。

| 位置 | 设计 |
| --- | --- |
| 首页顶部 | 固定全局搜索框，直接输入完整单号或后四位。查询时下方显示匹配记录，点叉回到批次列表。右侧为主题按钮。 |
| 首页内容 | 批次操作集中放在一张卡片。保留新建批次和继续扫码。下方显示累计数量与历史批次。 |
| 底部导航 | 使用批次、扫码、设置三个等宽入口。扫码页也移除底部失败件快捷按钮。 |
| 失败照片 | 可从设置或批次详情找到集中补录。原有单件详情补录与补拍入口可用。 |
| 主题 | 默认海湾蓝，可切换青竹绿和深夜黑。主题选择立即应用，下次打开自动使用。 |
| 图标 | 以深蓝底、高对比条码、四角取景框和黄色扫描线识别扫码应用，支持系统自适应裁切。 |

界面使用原生控件。CameraX 取景、识别、录入、拍照、记录和 Excel 导出的数据与业务代码继续沿用原项目。

## 构建

使用 JDK 17 或 21、Gradle 8.9、Android SDK 35。执行 `gradle :app:assembleDebug :app:lintDebug`。
默认沿用 v0.15.0 的应用 ID。覆盖安装需要用旧版对应的私钥签名。当前交付使用 `-PquickScanSideBySide=true` 构建独立安装包，旧版本的记录和照片仍在旧应用中。
