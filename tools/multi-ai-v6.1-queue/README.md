# Multi-AI Chat Desktop v6.1 / WQ-B: 真正的 API 接力开发阶段

这个目录是独立任务队列原型，**不是 Chatbox + New API 已完整融合的正式软件**。旧版 AI 漫剧素材工作台在 GitHub main 中保持原样。

## 已实现

- 30集默认、每集三阶段，**会员网页版手动交接 / API自动阶段 / 混合模式**自由选。
- API 模式使用 OpenAI-compatible \`/v1/chat/completions\` POST，支持 New API、OpenRouter 或官方兼容服务，必须填写网关实际支持的模型 ID；真实 HTTP 回复经过结构核验才能推进。代码不伪造模型回答。
- 逐集生成只处理当前集，同集前一阶段**完整文本**传给下一阶段；保留小说总纲、单集设定、参考图编号和上一集状态。
- SQLite + SHA256 完整留档、人工终审、暂停/继续/重试，重启后 API 不确定状态标记 \`api_interrupted\`，**绝不默认重发已发出的请求**。
- 记录各模型 API 实际 \`usage\` 的 Token，**不根据 Token 伪造结算金额**；需查网关账单。
- Electron 桌面壳的 **系统托盘**：点击窗口关闭按钮隐藏窗口，任务进程继续运行；托盘菜单可打开或真正退出。
- 一切会员官网依然仅由用户手动在官方页面操作，**不支持无授权的网页登录自动提取回复**。

## API 配置

仅供开发、测试使用：通过**应用启动进程的环境变量**配置。API Key 从不暴露给浏览器脚本、任务数据库或GitHub源码。
- \`MAI_API_BASE_URL\`：默认 \`http://127.0.0.1:3000/v1\`，可以配置为 HTTPS 的 New API 中转站地址，必须是已获授权的端点。
- \`MAI_API_KEY\`：从 New API（或兼容平台）分配的用户 API Key。
- \`MAI_DATA_DIR\`：本机保存 SQLite 数据的位置，桌面版本会使用 Electron 的用户数据目录。
 
在 PowerShell 里启动调试版，例如：
\`\`\`powershell
$env:MAI_API_BASE_URL = "https://你自己的网关域名/v1"
$env:MAI_API_KEY = "在本机临时填写密钥"
npm install
npm test
npm start
\`\`\`
不要提交真实密钥、账号Cookie到GitHub，也不建议把明文 Key 长期写入系统环境变量。正式版将改为系统凭据加密保存及 UI 管理。

## 使用流程

创建30集任务 → 选择「纯会员网页」「混合」「全部API」 → 为需要自动执行的每个阶段填入上游提供的真实模型 ID → 开始。API 阶段自动依次请求；会员网页阶段需要打开官网手动发送并导入回复。**每集最后的人工语义审核是安全关卡**，尚未实现无监督30集全部自动生成，因此不会虚假显示“30集已自动完成”。

## 不包含

Chatbox/Gemini 的官方会员无人工自动交接、Chatbox 现成私聊界面完整移植、New API 网关一键部署、自动语义质量审查、跨平台会员自动操作、Windows 真机安装验收。许可证与官方规则继续按相关上游约束执行。
