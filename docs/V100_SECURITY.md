# 独独AI工作台 v1.0.0｜代码保护与发布验证

## 已实现

1. Windows NSIS x64 安装包；保持历史 App ID 和 userData 路径，避免因更名丢失本地账号。
2. Electron ASAR 打包、禁用部分危险运行入口的 Fuses 配置、ASAR 完整性验证配置。
3. JS 业务代码生产构建时选择性混淆；CI 仅改临时工作树，可维护源码保持不混淆。
4. 出于豆包原生 @ 兼容要求，`import-page`、`inline-mention-page`、`mention-page`、`voice-page`、`video-mode` 保持可序列化。
5. 发布前全量代码测试、混淆后运行测试、FFmpeg 实际尾帧测试、安装包 SHA256 检查。
6. API Key 仍用 Windows 当前用户的安全存储，不会放到公开安装包。

## 未实现或需外部证书

- **没有 VMProtect / Themida 商业加壳。** 它们需要合法商业授权、兼容性验证，并通常适用于需要保护的原生模块，而非直接保护 Electron 的 ASAR。
- **不能声称源码无法提取。** ASAR 不加密，混淆只能增加阅读和修改成本。一个会使用 AI 逆向工具的小白仍可能提取部分 JS 并尝试重建。
- **代码签名视 CI Secrets 决定。** 未配置 `CSC_LINK` 和 `CSC_KEY_PASSWORD` 时构建可以成功但不等于已签名。正式向陌生用户传播建议购买 Windows 代码签名证书。
- **不实现强制联网授权。** 免费桌面软件及用户资料继续本地使用，不上传素材作验证。

## 可选后续商业防护

如果未来付费独家算法具有商业价值，可把适合原生化的少量计算迁移到 C++/Rust DLL 后评估商业保护；真正需要保密的付费生成规则也可以托管在权限受控的云端。不得将密钥硬编码到客户端，不得未经用户许可上传剧本或图片。

## 安全验收清单

- 所有 DOM 序列化帮助函数在 v1.0.0 包中仍可执行。
- API Key、Cookie、用户个人项目、配置备份、开发 `.env` 不进入 NSIS 包。
- 安装签名证书状态单独报告，不得凭文件 hash 宣称可信发布者。
- 安装/卸载/再次安装不主动删除 `%APPDATA%\DoubaoCreativeHubPublic`。
- 正式包仅从经授权的 GitHub Release 交付，不使用第三方打包盗版保护工具。

注意：源代码混淆属于防止简单复制的措施，不是法律或技术上的绝对防复制保障。
