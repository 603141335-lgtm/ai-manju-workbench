# v0.9.3 验收记录和使用说明

### 右侧
选好当前段后，点击「发送稿预览」，可以立即查看图N=编号+人物姓名、音频N=人物声音的完整发送稿。原始提示词保存在 workspace.json，不因预览而修改。可点「仅同步文字到豆包」进行一次性填充；网页已有原生@时禁止覆盖。手工绑定/修改声音后立刻重新生成预览。

### 底部
每集整行展开，段落多行网格。未完成卡片右上角「已完成」可切换状态，完成卡片变成小卡并留在原位置，点击「撤销」复原。高级锁定/隐藏设置不删除旧数据。

### 重要限制
图片/音频附件上传后的网页确认、真正蓝色@的定位和完整性仍须真实豆包登录实测。自动化测试只检验无画布工作台逻辑和离线模拟 DOM，不能声称所有豆包网页模式都通过真实验收。用户输入原文不得压缩。
