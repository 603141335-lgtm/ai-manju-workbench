# 独独AI工作台 v1.2.1｜授权链接超时修复

- 旧版 v1.2.0 使用 Node.js `https.request` 发起授权 POST，默认未适配 Electron Chromium 系统代理，连接等待仅 9 秒。
- v1.2.1 在 Electron 主进程注入 `net.fetch` 作为授权专用网络通道，支持 Chromium 网络代理环境，超时调整为25秒。
- 设备签名、Ed25519 客户端凭证验证、云端 D1 和已生成永久卡密均保持兼容，**不需要重新生成卡密、重置设备，也不需要重新部署 Worker**。
- 离线授权失败时不能无签名放行；未能联网的设备仍需完成在线激活。
- 请先在原安装目录备份项目，安装新版后再激活，实际中国大陆网络与代理设置仍需 Windows 实机验证。
