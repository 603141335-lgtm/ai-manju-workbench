# AI漫剧素材工作台 v4.0 Lite · Windows 测试版使用说明

本版继续使用 **Microsoft Edge 原有用户资料**，不读取密码、不复制 Cookie、不修改浏览器扩展。

## 下载与启动

1. 打开 GitHub 仓库「Actions」页面。
2. 选择「v4 Lite Windows portable」运行记录。
3. 如果构建成功，在「Artifacts」下载 `AI-Manju-Workbench-v4-Lite-Windows-x64`。
4. 解压整个 ZIP，不要只单独拖出 EXE；打开 `AI-Manju-Workbench.exe`。
5. 这是尚未签名的测试版，Windows 可能显示软件来源提醒；请只从自己的 GitHub 仓库获取文件并核对用途。
6. 不需要卸载已安装的 Edge，也不要移动现有 Edge 用户资料目录。

## 第一次使用

1. 在主窗口选择本地参考图总目录，导入 TXT/MD 或粘贴多集提示词。
2. 按需收起剧集目录，把提示词浮窗移动到副屏或屏幕左侧。
3. 在「Edge 账号小窗」点击刷新，它会扫描 Edge 已存在的 `Default` / `Profile N` 用户资料，并显示独立目录编号。
4. 选中用户，点击「打开选中 Edge 用户的豆包」。
5. 在主窗口点击某段的「分配到账号小窗」，集数、段落会自动带过去。
6. 在 Edge 内手动生成，成功提交后回账号小窗点「已提交一次」。`0/2` 是手动登记，不是官方余额。
7. 生成视频后，账号小窗选择插件实际保存位置作为「下载目录」；另设一个「归档目录」。
8. 在账号小窗选择这次视频对应的已提交段落，点击「准备下载」，再用你原有的 Edge 扩展下载视频。
9. 下载完成并稳定后，在可以确认是唯一新文件的情况下自动归档为 `第10集_第03段_V01.mp4`。重复下载变为 V02、V03。
10. 检测到多个新视频、临时下载文件、无法写入时不强行归档；先手动核对。

## 重要限制

- 当前版本是**浮动窗口配合 Edge 原生窗口**，不是把 Edge 真正嵌进 Electron。
- 打开指定 Edge 用户的代码已经添加，但前台准确切换至已有窗口还须 Windows 真实环境验证。
- 用户资料名字可能重复，因此小窗显示 `Profile 1` 等真实内部标识，避免混淆。
- 现有无水印下载插件不做改写，不测试或保证平台许可与无水印结果；软件只管理落地到本地文件夹的视频。
- 一次「准备下载」只绑定一个明确任务。如果多个账号同时下载到同一个目录，不会按下载顺序猜文件归属。
- 仅保证自动化 Node 逻辑测试，不等于 Edge 真机、插件下载、多图拖拽都已验证。
- 如 Edge 扩展使用浏览器外目录，请在小窗内配置真实保存目录。
- 不要把你的登录资料、Cookie、私有剧本素材或测试视频提交到 GitHub。

## 遇到问题如何反馈

说明窗口名称（提示词 / Edge / 账号小窗）、操作步骤、错误消息，以及当前使用的 Edge Profile 编号。
涉及文件归档请另外提供扩展下载目录和一个无敏感内容的示例文件名。无需提供账号密码或 Cookie。
