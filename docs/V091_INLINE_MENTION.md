# v0.9.1 图号行内真实图片 @ 修复验收说明

## 用户确认的最终排版

- 支持选择两种排列方式的设计，但 v0.9.1 默认采用每行 `图1 = A15（A15.png） @A15.png`，其中 `@A15.png` 只能是豆包原生生成的富文本引用标签。
- 整组图片信息仅位于提示词最上方的「需要参考图」区，绝不在正文末尾补充散乱 @。
- 保留原有完整提示词；只在发送草稿中注入图号映射，不修改软件里的原文。

## 实施

1. 根据上传确认的正确顺序生成唯一的图号定位锚点。
2. 在 TipTap / contenteditable 编辑器中用 TreeWalker 精确查找文本节点并放置光标。
3. 光标置于该图号行末，通过 Electron 键盘文本输入触发官方 @ 菜单，精确按完整文件名选择。
4. 检查图号行内真实的 `data-mention` / 富文本 token，验证 filename 与 anchor 同行。
5. @ 菜单没有同名唯一选项时清除本次临时 ` @`，状态显示“仅图号映射，原生 @ 未验证”；不得移到最后一行。
6. 阻止切换账号或段落时继续执行，保留批量上传与尾帧逻辑。
