# AI漫剧工作台 v4.0 Lite · Edge 联动使用说明

## 核心功能
- 保留原提示词文档、参考图编号识别和原生多图拖拽。
- Windows 提示词小窗、Edge 账号小窗都可以移动、缩放。
- 使用原有 Microsoft Edge Profile，保留豆包会员登录和原下载插件。
- 安装一次 Edge 连接扩展后，点击工作台的“分配到账号小窗”，该用户当前豆包页面自动接收并填入完整提示词。
- 生成按钮仍由用户手动点击；账号生成 0/2 由用户自己登记。
- 下载时继续使用已有插件；软件只负责监控本地下载目录并归档视频。

## 第一次安装（完整包）
打开 GitHub Actions 里的 v4 Lite Windows portable 成功构建，下载 Windows-x64 便携版 ZIP，完整解压，双击 AI-Manju-Workbench.exe。不要只单独解压 EXE。

## 已有便携版时的小包更新
下载同一次构建的 AI-Manju-v4-Lite-app-asar-update，小包里只有 app.asar。
先完全退出旧工作台；备份旧程序 resources 目录里的 app.asar；把小包中的新 app.asar 复制到该目录覆盖旧文件；再启动原来的 EXE。
只适用于这套工作台的相近 Electron Windows x64 便携版；出现问题时恢复备份。

## Edge 扩展首次配对（每个 Profile 一次）
1. 下载 Edge-Manju-Connector 压缩包，解压到长期保留的文件夹。
2. 用需要连接的 Edge 用户打开 edge://extensions，打开开发人员模式，点“加载解压缩的扩展”，选择包含 manifest.json 的目录。
3. 打开工作台“Edge账号小窗”，点击这个 Edge 用户（Default 或 Profile N，用真实内部编号区分相同显示名称）。
4. 点击“复制此用户的连接密钥”。
5. 在该 Edge 用户里点扩展“AI漫剧工作台 · Edge连接器”，粘贴密钥，点“保存并连接”。
6. 扩展提示已连接即可。其他 Edge 用户重复上述安装和配对，原来下载插件不用卸载。

## 日常操作
1. 在账号小窗选择本次 Edge 用户。选择后系统会记住，后面不必每次选择。
2. 在提示词文档选择第几集、第几段，点“分配到账号小窗”。
3. 切换到对应 Edge 用户的豆包网页，扩展自动向当前正确的空白提示词输入框填入文字。如果网页有多个输入框，先手动点一下正确输入框；已有内容时不会强制覆盖。
4. 从原提示词工作台拖入参考图，检查内容后自己点“生成”。
5. 提交后在账号小窗点“已提交一次”，记录本地 1/2 或 2/2。这不是官方剩余额度。
6. 视频完成后，在小窗选择这个已提交任务，点“准备下载”；确认下载目录是扩展实际写入的位置。
7. 在 Edge 用原插件下载一条视频。工作台确认只有一个新文件且完整后，存入例如 第10集/成片/第10集_第03段_V01.mp4。再次下载变成 V02，不覆盖旧文件。
8. 如果同时出现多个新视频或仍有下载临时文件，则不会猜测文件归属；保留源文件等待手动整理。

## 重要限制
- 连接扩展只操作指定豆包域名中的文字输入区域，不自动点击生成，不读取浏览器密码和 Cookie。
- 本机通信限定 127.0.0.1:18741，采用每 Edge 用户独立的随机配对密钥。
- 需要工作台运行和该 Edge 用户的豆包网页处于前台，才能自动填入。
- 豆包可能修改网页编辑器结构，若无法自动填入，仍可通过“复制提示词”手动粘贴。
- 原下载插件未被替换；软件不负责去水印，只整理已经下载到本地的视频。
- 从旧版升级前建议保留项目备份和旧 app.asar。
