# AI漫剧素材工作台 · 纯文档版 v4.2

根据用户的最新截图重新设计：移除浏览器账号及下载相关功能，保留完整提示词与原生多图片拖拽，增加两级目录+文档、紧凑可缩放面板以及跨段选择清除。

## 技术实现
- 基于原始 main 分支独立开发，未引入 Edge 连接器、账号小窗、下载监听及其IPC。
- `project.groups`：大标题、小标题的非破坏性树结构；`episode.groupId` 把现有剧集作为文档纳入目录。
- 新建文档沿用现有 episode/segment 结构；完整原文及参考图索引仍为旧版结构。
- 提示词与参考图区共同使用可调整高度的布局容器，上下默认各占一半，文字在内部滚动、复制始终取完整 `seg.text`。
- 全选图片或文字时自动清理上一段旧选择状态；保留原有原生文件拖拽代码。
- 旧项目加载不会丢失剧集；首次从旧 schema 升级前创建本机文件备份。

## Windows 测试
GitHub Actions 会运行参考图编号回归和模拟DOM按钮交互测试，然后打包 Windows x64 便携版。
UI 自动测试覆盖：新建大标题/小标题/文档、文字全选、跨段图片全选、复制完整提示词、上下同步调整高度。
真实跨窗口向 Edge 豆包上传多张参考图片仍建议 Windows 实机验收。

## 升级
现有 v4 便携版可完全退出软件后，把 `resources/app.asar` 备份，再用本分支成功构建提供的 `AI-Manju-Documents-app-asar-update` 中的 `app.asar` 替换。
如果旧软件使用了不同的 Electron 运行环境，请改为下载完整版便携包。
