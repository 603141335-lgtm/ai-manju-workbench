# v4.0 Lite · Microsoft Edge 用户辅助工作台

## 已确认的产品范围
- 原素材工作台保持独立自由窗口；保留多集文档、完整提示词、参考图识别与原生图片拖拽。
- 另开独立可缩放 Edge 账号小窗，使用 Windows 已存在的 Edge Profile，不导入密码和 Cookie。
- 从账号小窗打开所选 Profile 的 Edge 豆包窗口；浏览器原扩展和下载方式保持不变。
- 用“已提交一次”手动记录视频任务，关联集数、段落；每 Profile 默认展示 /2。手动撤销和归零。
- 下载归档下一阶段实现：识别文件完成、匹配任务、命名 第10集_第03段_V01.mp4，无法确认归属时必须人工选择。

## 当前开发状态
- 已添加 app/edge-profiles.js：扫描 `%LOCALAPPDATA%\\Microsoft\\Edge\\User Data` 里的 Default / Profile N，仅读取用户显示名。
- 已添加 app/edge-ledger.js：不涉及官方额度的本地任务记录以及文件名格式。
- 已添加 app/edge-window.*：可缩放账号小窗、选择用户、打开 Edge、登记/撤销/归零。
- app/main.js 在 Windows 启动账号小窗。
- **未验证 Windows 真机、Edge 已登录窗口复用、原网站多图拖拽和第三方下载插件。**
- **下载文件监控和自动重命名尚未接入。** 不应将其标记为已完成。

## 技术限制和约束
- 不将 Chrome / Edge 的用户目录移动、复制、重写到软件内部。
- 不能强行把 Edge 嵌进 Electron；用真实 Edge 窗口实现。
- 手动计数与官方会员剩余额度没有关系；失败的任务由用户撤销或调整。
- 软件不开发去水印、不控制自动批量生成、不绕过平台限额。
- 所有账号和任务数据保存在本机 Electron userData 中，不推送到 GitHub。
- 生成失败、浏览器退出、下载失败不可自动假设会返还额度。

## 高风险点
- 多个账号任务并发下载时，不能按文件修改时间盲猜集数/段落。
- Edge 自身已运行时，`--profile-directory` 会请求对应用户窗口，实际前台激活行为需要 Windows 实测。
- Chrome / Edge 下载插件可能绕过浏览器下载 API，需要先调查插件具体保存方式。
- 现有原生拖拽代码在不同网页上传区域可能出现不兼容，保留旧版回退。
