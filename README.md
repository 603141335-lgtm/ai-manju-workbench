# 豆包创作舱 v0.9.5｜公开分发版框架

**先看完整方案：** [公开版数据隔离、联网社群公告与低内存设计](docs/v0.9.5-public-framework.md)

**本分支是独立的公开分发版本，不覆盖 v0.9.4 作者工作版。** Windows 新用户首次打开为空白工作区，保留25个未登录的豆包账号位置。公开版使用全新的 App ID、独立的数据目录和下载目录，不自动迁移原作者账号、Cookie、提示词或素材。

新增顶部「社群·公告」入口，未来可通过一个固定 HTTPS JSON 远程编辑公告、版本下载入口、微信二维码、QQ群内容；服务器未配置时显示占位信息。新增「性能」菜单，默认同时最多2个浏览器视图，另可选1或3个，**释放后台页面前须人工确认**，生成/上传任务不能被可靠自动识别。

**公开版构建：** 设置 DOUBAO_NOTICE_URL（可不设置、但不联网读取公告），然后依次执行 npm install、npm run check、npm run dist:win。正式向普通用户发布要检查构建清单、签名、SHA256，并从全新 Windows 账户实测无旧登录数据。

**已知限制：** 真实豆包生成和蓝色 @ 依赖其网页更新；公告管理后台和真实广告配置尚未提供。当前基础框架不负责自动安装新版，只有用户主动打开下载链接。

## v0.9.4 既有工作台功能（继续保留）


本分支继承 v0.9.4 的已有功能，公开版另外隔离身份及用户数据。

## 已实现的代码改动

- 进入豆包 / 切换账号后，在官方页面尝试进入视频生成模式，核验 Seedance 2.0 Fast / 16:9 / 15秒；点击一键导入前再次核验，未通过不静默执行上传。
- 保留完整原始提示词、图片编号映射与网页原生蓝色 @ 的真实性判断。上一段尾帧正在提取时等待，不要求第一段预先存在尾帧。
- 下载完成后仍由 Electron 捕获网页原生下载，由 FFprobe/FFmpeg 提取靠近末尾的有效非黑帧；尾帧候选历史保留，未锁定则最新合法下载生效，手动绑定版本受保护。
- 下载归档优先按**当前账号最近成功导入**的段落关联；无法确定来源时保留下载并提示，不在其他账号的工作区里误绑定。
- 下方界面上排为可横向滚动的方形剧集卡，下方为方形段落网格；集和段可以移入回收站并撤销，原视频、账号登录和参考图本体不删除。跨段引用采用持久前段 ID，删除后仍可引用回收站内原前段的尾帧。
- 新增 `tests/v094.test.js`，覆盖恢复、引用与模式状态判断。

## 原功能保留

真实内嵌豆包网页版、25个账号位置、三个同时活跃的内嵌会话、批量导入剧集、A01小李等编号映射、批量参考图、人物音色、图片拖拽、原文和发送稿预览、自动命名下载、备份与恢复。

## 构建与安装

```sh
npm install
npm run check
node --test tests/v094.test.js
npm run dist:win
```

在 GitHub Actions 的 `build-windows.yml` 中也配置了 Windows NSIS 安装包构建。进入 Actions 工作流或本分支对应 PR 检查，成功之后下载 `Doubao-Creative-Hub-Setup-v0.9.4-x64` 构建产物；构建失败时不要安装未验证产物。

**重要限制：** 视频创作模式选择器、文件上传、原生 @ 组件随豆包网页更新而变化。本版尚未完成用户登录态的 Windows 豆包实机验收。无法真实确认的操作会提示手动核验；代码不会自动点击网页发送/生成。

原分支 `doubao-creative-hub-STABLE-v0.9.3` 不受此分支改动影响。
