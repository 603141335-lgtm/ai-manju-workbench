# 豆包创作舱 v0.9.4｜原版增量升级

基于原 **v0.9.3 Electron Windows 真内嵌豆包浏览器工作台**，不替换原软件身份。

## 本版实现
- 自动检查当前账号网页是否在「视频生成」模式，尝试选中 Seedance 2.0 Fast / 16:9 / 15秒，逐项回读；若账号没有或网页改版，明确提醒手动核验，不会误报成功。
- 一键导入先检查豆包视频模式，遇到正在提取的尾帧会自动等待；继续使用真实网页附件检查与原生 @ 尝试，不自动发送或生成。
- 豆包视频通过原生下载完成后，使用 FFmpeg 截取末尾有效 PNG 帧，保留多个下载版本；用户未锁定时最新合法下载更新图1。
- 防止多账号/多段下载误关联：只有已成功导入、当前选中段也一致且无其他待下载段落时才自动绑定；来源不确定的下载需要点「关联当前段」确认一次。
- 底部横向方形剧集卡 + 当前集网格方形段落卡，均可以删除到回收站、恢复。删除从不自动清除原视频、原图、账号 Cookie、提示词。
- 现有账号位、内嵌网页、参考图编号/人物名、音频、分段、备份、下载归档等功能保留。

## 源码和打包

- 基线分支：`doubao-creative-hub-STABLE-v0.9.3`
- 升级分支：`feature/v0.9.4-video-tailframe-ui`
- 安装身份仍为 `com.manju.doubao.creativehub`，覆盖安装保留用户目录。
- Windows GitHub Actions 工作流 `.github/workflows/build-v094.yml` 执行检查、下载 LGPL FFmpeg、打包 NSIS 安装程序。
- 本地验证：`npm install` → `npm run check` → `npm run dist:win`。本地打包前须保证 `vendor/bin/ffmpeg.exe` 和 `vendor/bin/ffprobe.exe` 存在。

## 重要限制
自动模式选择和原生蓝色 @、豆包网页版图片上传必须在本人 **Windows 已登录豆包账号** 中做实际验收。静态检查及离线模拟测试无法证明网站所有版本的 DOM 均兼容。软件不会读取账号口令、私自点击发送、绕过平台额度或自动发起付费生成。
