# Multi-AI Chat Desktop v6.1 — WQ-A 可运行任务内核

**当前交付范围：真正可运行的本地30集多 AI 任务队列 + 中文网页版任务中心。**

这不是完整的 Chatbox 改造版，也不是 Windows 安装包。本包用于先验收逐集调度和数据安全，然后合并到 Chatbox 的 Electron 主进程。严禁把本地模拟测试当成会员网页自动生成成功。

## 已实现
- 1–200集项目创建（默认30集），每集 ChatGPT→Gemini→其他AI 三个逻辑阶段，角色与阶段可配置。
- **完整原始故事**和本集提纲带入每次提示词，不做隐式摘要/截断；最多40万字符，超过直接提示错误。
- 当前步骤状态为 `waiting_web`：可复制提示词，在官网**人工**发起、复制真实回复回工作台。
- 回复导入后存成新版本，自动校验非空/短文/集号疑点；自动推进下一阶段，不伪造模型答案。
- 最后一步通过结构检查后进入人工语义质检；人工确认并记录连续性状态，才允许下一集开始。
- SQLite WAL 持久化、事件日志、每阶段版本文件、SHA-256 校验、原子文件写入。
- 暂停、继续、单阶段重试、进程重启后恢复、已完成集导出。
- `node --test` 覆盖30集完整模拟、恢复、失败重试和误操作拦截。

## 运行（需 Node.js 22.13–22.x）

```powershell
cd Multi-AI-Chat-Desktop-v6.1-WQ-A
npm test
npm start
```

在 Windows Chrome 或 Edge 打开 `http://127.0.0.1:17861`。本机服务绑定 `127.0.0.1`；所有任务默认保存在项目下 `local-data/`。使用 `MAI_DATA_DIR` 环境变量可设置保存位置。不会连接任何第三方网页，也不会发送或记录帐号密码、Cookie、API Key。

**网页辅助模式操作：** 新建任务 → 开始 → 复制提示词 → 打开 ChatGPT/Gemini 官网手动发送 → 将完整回复粘贴回工作台 → 导入 → 进入下一阶段 → 最后人工确认本集完整性后开始下一集。

## 尚未实现（后续里程碑）
- Chatbox 主程序内的原生四区 UI、真正的 AI 私聊/群聊连接器和 Token 账单；这些会在下一阶段与上游 Chatbox 实际源码集成。
- 会员网页的无人值守自动发送与自动读取，受平台许可、网页变化与授权限制，不能承诺。
- Electron 托盘运行、Windows `.exe` / NSIS 安装包。当前是 Node 本地原型，窗口关掉后若 `node` 进程仍在队列可读，但不等于后台网页能自动写剧本。
- 语义级剧情完整性自动审核（目前仅结构规则 + 人工确认）。
