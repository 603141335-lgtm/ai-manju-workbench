# 豆包创作舱 v0.9.3｜浏览器工作台升级版

这是 **真实内嵌豆包网页版** 的 Electron Windows 工作台，基于 v0.9.2 增量升级。

## 新增
- `A01小李`、`A01-01小李` 人物名与参考图编号拆分；识别有歧义时阻止错误绑定。
- 原始提示词独立保留、发送稿实时预览、一次性写入文本、可独立重同步文字。
- 顶部图号、声音对应关系自动同步，真实蓝色 @ 仅通过网页原生组件检测判定。
- 底部全宽剧集目录，点剧集展开换行段落卡，已完成段缩小且可恢复；旧隐藏/锁定状态和数据仍然保留。

## 原功能保持
25 账号位独立持久会话、豆包真实浏览器、剧集导入、图片批量上传、角色音频、跨段尾帧、下载归档。

## 测试和打包

```sh
npm install
npm run check
python tests/ui_v093_browser.py
npm run dist:win
```

Windows GitHub Actions 构建 NSIS 安装包，保留原 App ID `com.manju.doubao.creativehub` 和用户数据目录。安装前建议备份项目。

**真实豆包网页端图片/音频原生 @ 及上传仍需要 Windows 登录环境实机验收。** 模拟页通过不能算实际支持。**本版不是 Themida/VMProtect 商业加壳版本。**
