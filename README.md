# 豆包创作舱 v0.9.0 · 浏览器登录工作台 + 一键导入（测试版）

这是基于能在软件内登录豆包官方网页版的 **v0.7.1 Electron 浏览器工作台** 的增量升级，不是单独的文档工作台，也没有重新引入无限画布。

## 新增「⚡ 一键导入：提示词＋参考图＋@」

1. 工作台右侧选中集和段，已配置的参考图库根据「需要参考图」自动匹配 A01、A01-01、AG14、B13、C36 等编号。
2. 点击一次新增按钮，软件逐张将**本地真实图片**送给当前豆包聊天网页自己的上传控件（File + DataTransfer + input/change）。
3. 每张图片必须在网页有对应附件文件名后才继续；只有缩略图没有名称时需人工核对，核对后继续，不当作软件自动成功。
4. 图片全部确认后，在豆包网页输入框填写当前段**完整原文**并追加“图1=A15、图2=A32……”映射表，回读核对。
5. 如果豆包当前聊天模式确实提供原生 @ 图片菜单，尝试逐张插入并核实标记；否则保留图号说明，不把普通文字当成真实 @。
6. 任务过程中可以取消。**绝不自动发送消息、读取 Cookie 或修改原段原文。**

> **重要：** 已完成本地单元测试和 Chromium 模拟网页文件选择／文本写入验证；尚未在用户真实豆包账号中完成上传及原生@的端到端验收。以【集成测试版】交付，不保证豆包官方网页后续改版后的兼容性。

## 保留原有全部功能

- 中央真实豆包网页 WebContentsView；5组25账号位，每账号 `persist:doubao_<ID>` 独立登录会话。
- 剧集、段落、TXT/MD批量导入、参考图编号、图片拖拽、下载管理、备份、隐藏锁定。
- 原 `appId=com.manju.doubao.creativehub`，原 Windows NSIS 安装身份和 `userData` 目录，支持用新安装包覆盖升级；不会新建另一套软件。
- 未集成独立画布，未实现商业 Themida 加壳。

## 安装与测试

Windows 用户下载对应版本的 NSIS 安装包，覆盖安装前导出工作台项目备份。在已经登录的豆包聊天页测试 A15 单张、A15+A32 两张、6张的顺序上传和图号对应。看右侧显示的「自动确认」「人工确认」「原生@验证」是否与网页一致。

## 本机开发

```bash
npm install
npm run check
npm run dist:win
```

正式 Windows 构建流水线只在临时 CI checkout 中混淆 JS 并产出 NSIS 安装包，不修改 GitHub 上可维护的原源码。配置 `DOUBAO_UPDATE_URL` 并真实发布更新元数据后才能启用软件内在线更新；否则使用覆盖安装。

完整设计、保护边界、功能验证与回退方案参见 [`docs/V080_ONECLICK_INTEGRATION.md`](docs/V080_ONECLICK_INTEGRATION.md)。
