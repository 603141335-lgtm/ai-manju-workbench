# AI漫剧工作台 Edge 连接器

## 首次安装（每个需要联动的 Edge 用户都安装一次）
1. 解压 \`Edge-Manju-Connector.zip\` 到一个长期保留的文件夹，不能安装后删除。
2. 在对应 Edge 用户窗口打开 \`edge://extensions\`，启用开发人员模式。
3. 点击「加载解压缩的扩展」，选中含 \`manifest.json\` 的文件夹。
4. 运行 Windows 工作台，打开「Edge 账号小窗」，选择同一个 Edge 用户资料（Default / Profile N）。
5. 点击「复制连接密钥」，打开此 Edge 用户里的「AI漫剧工作台 · Edge连接器」图标，粘贴并点「保存并连接」。
6. 扩展显示已连接后，进入 \`https://www.doubao.com/\`，工作台选择段落并分配给对应 Edge 用户。
7. 扩展只尝试写入当前聚焦的豆包输入框；如果页面有多个输入框，请先点击正确的提示词输入框。

## 权限和安全
- 只访问 \`doubao.com\` 域名下的网页，及本机 \`127.0.0.1:18741\`，不向其他服务器发送提示词。
- 配对密钥保存在当前 Edge 用户的扩展存储中；不同 Edge Profile 必须分别配对。
- 不读取 Cookie / 登录密码，不使用调试器权限，不自动点击生成，不修改无水印插件。
- 豆包网页编辑器可能升级，遇到无法填入可继续使用工作台「复制提示词」手动粘贴。
- 关闭 Windows 工作台后，扩展无法自动填写提示词。
