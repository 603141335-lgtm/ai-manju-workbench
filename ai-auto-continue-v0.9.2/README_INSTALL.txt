AI自动续聊助手 v0.9.2 · 方形平台卡片与任务切换版
================================================

本版基于 v0.9.1 轻简版增量升级，保留原有自动续聊、图片附件、模型读取、历史记录和同平台多任务功能。

【本版更新】
1. 删除顶部“全部开始 / 全部暂停 / 继续全部 / 全部新任务”整条控制栏。
2. ChatGPT、Gemini、豆包、DeepSeek 改为四张方形平台卡片。
3. 每张卡只保留：开始、暂停、继续、重新，按任务状态启用/禁用。
4. 点击平台卡片主体，即可切换到该平台当前运行中的任务；没有运行任务时优先切换最近暂停/待处理任务。
5. 任务设置顶部增加任务 A、B、C……小方块；“＋ 新任务”创建新的独立任务和聊天窗口。
6. 任务设置重新分成：基础设置、模型设置、创作指令与图片、其他设置。
7. 最大同时运行数固定为 3。第4个及之后的任务自动进入等待队列；有任务释放位置后由扩展后台自动启动。
8. 进度、已保存内容、历史任务和运行日志保留原有功能与主要布局。
9. 不恢复 Skill 文件库和附件发送功能。

【升级安装】
1. 在 v0.9.1 中打开“数据管理”，点击“导出全部记录”，保存 JSON 备份。
2. 下载并解压 AI_Auto_Continue_v092_INSTALL.zip。
3. 将解压后的文件直接覆盖原 v0.9.1 扩展文件夹（必须覆盖 manifest.json、dashboard.html、dashboard.js、runner.js、background.js、style.css 和 icons）。
4. Edge 地址栏输入 edge://extensions，找到“AI自动续聊助手”，点击“重新加载”。
5. 刷新已打开的 AI 聊天网页，再打开控制台，确认版本显示 v0.9.2。
6. 先点击一个平台卡片，再在下方任务设置里选择任务 A/B 或“＋ 新任务”。

不要卸载旧扩展，不要删除原扩展文件夹。v0.9.2 沿用 aac9:* 本地存储键，正常覆盖升级可保留任务正文、历史、模型偏好、图片关联和窗口绑定。

【操作说明】
- 点击平台卡片空白区域：切换到该平台正在运行的任务；多个运行任务时优先选择最近更新的任务。
- 点击任务 A/B/C 小方块：切换到指定任务，下面的设置、进度、已保存内容和日志随之切换。
- 点击“＋ 新任务”：创建新的任务实例并打开独立聊天窗口；新任务不会自动开始。
- 平台卡片的“开始、暂停、继续、重新”只作用于该平台当前显示的任务。
- “重新”会先归档旧运行记录，再使用原任务配置从第1步重跑；旧正文保留在历史任务中。
- 同时最多3个任务运行。超过上限的任务进入后台等待队列，浏览器保持开启且目标 AI 标签页保持可用时自动启动。

【安全与兼容说明】
- 任务切换只改变控制台当前查看对象，不会暂停其他平台任务。
- 平台卡片按钮不会触发卡片主体点击，避免误切换。
- 无法确认输入框、发送状态或回复完成状态时，原有执行器仍会安全暂停，不会盲目重复发送。
- 浏览器需要保持开启，电脑不能休眠；网页登录失效、平台更新、会员额度或限流可能影响自动化。
- 本版完成的是本地模拟页面测试，不代表已在用户真实登录的四个平台网页完成实机验证。

【版本】
- manifest version: 0.9.2
- 固定并发上限：3
- 动态任务实例：每个平台 A-Z
- 运行队列：由扩展后台 service worker 调度
