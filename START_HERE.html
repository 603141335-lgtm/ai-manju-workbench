豆包创作舱 v0.3｜真正的四区融合工作台

左账号／中间真实豆包网页／右完整提示词和参考图／下剧集分段。版本升级不会主动删除旧的豆包登录环境。

Windows 启动

  1. 解压整个 ZIP 到一个新文件夹，建议路径使用英文，例如 D:\DoubaoCreativeHubV03。
  2. 已经运行过 v0.1.1：可把旧文件夹的 node_modules 整个复制进本工程，避免再次下载 Electron。
  3. 双击 START_Doubao.cmd；若 Electron 二进制缺失，会尝试修复。
  4. 启动后：先通过底部「导入 TXT/MD」或「粘贴多集」载入提示词，再「参考图目录」选择图片根目录。
  5. 底部点击第X集展开多层剧集目录；可隐藏完成段、锁定内容防误改，右边自动显示原始提示词和编号对应图片。多选或拖图上传；失败时点击「备用上传文件夹」。

右侧下载管理

在中间豆包官方网页中正常点击下载，软件会按项目/剧集/段落/账号自动命名与保存；需要原图请优先使用网站许可的原始下载。扩展兼容仅支持用户选取已解压扩展文件夹，查看权限后确认载入当前账号；实际去水印能力没有在 Windows 豆包上验收。不支持的扩展请继续使用原 Edge 配置文件。

打包 EXE

这份下载的是工程包，不是已经编译的 EXE。你可以双击 BUILD_Windows_EXE.cmd，构建成功后在 release 文件夹获得便携版 EXE；也可以使用工程自带的 GitHub Actions workflow。

数据安全

账号仍存储在旧的 Electron 持久化分区中，原账户配置文件 config.json 不因升级而覆盖。新的漫剧项目存于 workspace.json；旧项目通过手动选择 JSON 备份只读迁入。升级前仍建议做账号清单和漫剧项目备份。

跨内嵌网页拖拽是否被豆包接收依网站实际行为，界面演示和自动化测试不能代替 Windows 实机。
