# AI漫剧工作台 · v4.6 四套界面方案（仅设计样机）

> **本分支只新增设计预览文件。** 完整提示词、参考图片、解析、编号识别、文档目录、跨窗口拖图以及 v4.5 的展开／折叠等生产代码全部未修改。

## 如何在 Edge 里预览
1. 打开 [四套布局 HTML](./v46-four-layouts.html)。
2. 在 GitHub 的文件页点击右上角的 **Download raw file**（或 Raw 后使用「另存为」）。
3. 将下载的 `v46-four-layouts.html` 保存到电脑，双击用 Microsoft Edge 打开。
4. 顶部可以点击 A、B、C、D 切换风格；可以点模拟的折叠、图片、目录右侧“···”查看按钮位置。页面不读取或修改任何本地剧本与账号信息。

## 方案说明

| 方案 | 风格 | 主操作按钮位置 | 最适合 |
|---|---|---|---|
| A | 云文档清爽型 | 复制 / 折叠在段落标题右侧；拖图在底部 | 习惯云文档、需要快速阅读分镜 |
| B | 专业制作台 | 固定右侧竖排操作条；目录深色 | 频繁切换段落、持续复制、拖入图片 |
| C | 专注卡片型 | 复制 / 收起紧贴提示词顶部，段落独立大卡片 | 审阅提示词较多、需要清晰分隔 |
| D | 高密度精简型 | 操作按钮压缩到标题行和提示词上方 | 一集有十几到几十段，想一屏看更多 |

四套方案均遵守以下共性：左侧两级目录和“···”菜单；每段先完整提示词、后参考图；收起只保留标题；图片可以多选/整组拖；整个窗口与左右宽度可调整。预览使用的文字和图片色块仅用于布局演示。

## 后续正式开发
